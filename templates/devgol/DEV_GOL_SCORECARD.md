# DEV GOL UI Scorecard

Chấm /100 theo các tiêu chí:

| Tiêu chí | Điểm tối đa |
|----------|-------------|
| Hierarchy (typography, spacing) | 20 |
| Accessibility (contrast, labels) | 25 |
| States (loading, error, empty) | 25 |
| Visual consistency (tokens, components) | 15 |
| Responsive / viewport | 15 |

- Dưới 85: tự sửa tiếp
- Từ 85: có thể báo đạt
- Từ 92: chuẩn DEV GOL Gold
